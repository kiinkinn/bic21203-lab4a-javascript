## Introduction
This repository contains the exercises for Lab 4a: Client Side Scripting using JavaScript.

## Question 1 - Interactive Text Changer
A webpage that can changes paragraph text when a clicked a button.

## Question 2 - Smart Number Validator
A webpage that will checks whether the number that entered is lower, higher or equal to 10. 

## Question 3 - Dynamic Number Generator
A webpage that generates a numbered that list from 1 to 5 using a JavaScript for loop.

## How to Run
1. Download or clone this repository.
2. Open the required question folder.
3. Open index.html using a web browser.
